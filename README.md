# 👋 Hi, I'm Nihar

M.Sc. graduate in International Software System Science, based in Germany. I build across software engineering, cloud infrastructure, and machine learning, and enjoy understanding systems from the ground up - from CPU architecture to Kubernetes clusters.

My recent projects include an AI platform built from scratch, featuring a custom GPT, image and video diffusion models, and a Jarvis-style interface, as well as a full-stack career intelligence platform backed by cloud infrastructure. I’m also exploring PhD opportunities in generative AI for games and interactive systems.

- 🔭 **Sainyx** - an AI platform built from scratch with a character-level GPT, image/video DDPM, and a Flask + HUD frontend
- 🛠️ **CareerOps** - a career intelligence platform built with Next.js and FastAPI, deployed on GCP with Terraform
- 🌱 I enjoy learning by building and understanding systems from first principles
- 🎮 Outside of code: Dragon Ball Z, anime, and games like Tekken, Elden Ring, God of War, Mortal Kombat, and Street Fighter
